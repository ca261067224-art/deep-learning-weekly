
# Deep Learning Weekly

## 项目介绍

这是我的深度学习课程学习记录仓库，主要记录每周的理论学习、代码实践、模型训练、实验结果及个人总结。

通过 PyTorch 完成不同神经网络模型的构建、训练和性能比较，逐步掌握深度学习的基本原理和实践方法。

## 学习环境

- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib
- Google Colab
- CUDA
